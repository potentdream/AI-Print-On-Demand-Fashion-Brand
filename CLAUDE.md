# Repo guide

Two unrelated projects share this repository:

- **`aunty/` — ACTIVE.** AI-matchmaker dating app for India. All current work
  happens here. Start every session by reading `aunty/CLAUDE.md`,
  `aunty/PROGRESS.md`, and the last ~10 entries of `aunty/DECISIONS.md`.
  Full spec: `aunty/SPEC.md`.
- **Root (`automation/`, `designs/`, `quotes/`, `scripts/`, `templates/`,
  root `package.json`) — dormant.** Print-on-demand fashion-brand workflow
  from an earlier project. Do not modify or delete unless the human asks.

CI for Aunty lives at `.github/workflows/aunty-ci.yml`.
