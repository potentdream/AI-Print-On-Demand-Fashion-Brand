# Quotes Master — Canonical Quote Bank

The **single source of truth** for every quote. If a quote isn't here (spelled
exactly), it shouldn't be on a product. Downstream files copy from this bank —
never retype a quote from memory.

## How to read this table

- **Quote** — character-exact text, including punctuation, capitalization, and
  intended line breaks (shown with `/` where a line break is wanted).
- **Mood** — one or more of: `savage`, `cute`, `luxury`, `desi`, `minimalist`,
  `party`, `gym`, `travel`.
- **Products** — best fit: `tee`, `tote`, `sticker` (may list several).
- **Slug** — folder slug (see `automation/naming-rules.md`).
- **Status** — `idea`, `in-design`, `live`.

## Brand voice guardrails

Bold · cheeky · feminine · stylish · modern · slightly savage · culturally
playful. **Never** vulgar, explicit, hateful, or punching down. Desi/traditional
references are affectionate and empowering, never mocking a culture.

## Adding a new quote — checklist

- [ ] Text is bold, cheeky, feminine, confident — on brand.
- [ ] Not vulgar, explicit, hateful, or mocking a culture.
- [ ] Punctuation, capitalization, and intended line breaks recorded exactly.
- [ ] Mood tag(s) assigned.
- [ ] Product fit tag(s) assigned.
- [ ] Slug generated per naming rules.
- [ ] Row appended to the table above (never edit an existing live quote's text).
